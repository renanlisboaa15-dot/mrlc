# MRLV Digital

Site institucional responsivo para venda de serviços digitais.

## Como usar
1. Abra `index.html` no navegador.
2. Para receber pedidos pelo WhatsApp, abra `script.js`.
3. Troque `WHATSAPP_NUMBER` pelo seu número no formato internacional, sem `+`, espaços ou símbolos.
   Exemplo: `5511999999999`.
4. Substitua os cards do portfólio pelas imagens dos seus trabalhos quando quiser.

## Publicar grátis
Você pode publicar estes três arquivos em serviços como GitHub Pages, Netlify ou Vercel.

## Arquivos
- `index.html` — estrutura do site
- `style.css` — visual e responsividade
- `script.js` — menu, animações e formulário/WhatsApp
